================================================================================
                          XBPQ 插件调用示例
================================================================================

XBPQ 是 CatVodSpider 框架的影视爬虫，以 && 正则截取为核心规则语法，
支持中英文双键配置、CSS 选择器模式、多线聚合、反爬绕过、图片代理、
弹幕加载、M3U8 解析、{{变量}} 模板、动态域名、WebView 渲染等增强特性。

================================================================================
一、TVBox 外挂调用基本格式
================================================================================

在 TVBox 配置 JSON 的 sites 数组中添加：

{
    "key": "csp_XBPQ_站点名",
    "name": "站点显示名(XBPQ)",
    "type": 3,
    "api": "csp_XBPQ",
    "searchable": 1,
    "quickSearch": 1,
    "filterable": 1,
    "ext": "站点配置JSON的路径或URL",
    "jar": "XBPQ.jar 的路径或URL"
}

参数说明：
- key：唯一标识，建议 csp_XBPQ_ 开头
- name：显示名称
- type：固定 3（Spider 类型）
- api：固定 "csp_XBPQ"
- searchable：1=支持搜索，0=不支持
- quickSearch：1=支持快搜，0=不支持
- filterable：1=支持筛选，0=不支持
- ext：站点规则 JSON，支持：
    * clan://TVBox/xxx/xxx.json     （clan 本地路径）
    * http://xxx.com/xxx.json       （网络 URL）
    * ./xxx.json                    （相对路径）
    * 直接 JSON 字符串              （内联配置）
- jar：XBPQ.jar 的位置

场景 15：工具链 [工具:xxx] 用法
────────────────────────────────────────────────────────────────

{
    "站名": "工具链示例",
    "主页url": "https://www.example.com",
    "搜索url": "https://www.example.com/search.php?wd={wd}[工具:解b64]",
    "分类": "电影$1",
    "分类url": "https://www.example.com/{cateId}/page/{catePg}.html",
    "数组": ".item&&</div>",
    "链接": "href=\"&&\"[工具:解url]"
}

支持的 [工具:xxx] 语法：
  [工具:源码]                抓取发布页 HTML 并返回（配合 发布页 字段使用）
  [工具:重定向]              跟随 HTTP 重定向获取最终 URL
  [工具:解url]               URL 解码
  [工具:解b64]               Base64 解码
  [工具:SHA]                 SHA-256 哈希
  [工具:1截取N]              按分隔符取第 N 个片段（N 从 1 开始）
  [工具:随机字符-N-唯一]      生成 N 位随机字符串
  [工具:源码转b64#解密aes-key-iv-AES/CBC/PKCS7Padding]  AES 解密

[替换:a>>b#x>>y] 语法可写在任意规则值末尾，不限于 [工具:xxx] 内。

四、搜索结果字段映射
================================================================================

搜索模式=0（JSON 模式）时，自动探测含 vod_id/vod_name 的数组，
并兼容以下非标字段名映射：

  id / vod_id / playlet_id  →  vod_id
  name / vod_name           →  vod_name
  pic / vod_pic             →  vod_pic
  remarks / vod_remarks     →  vod_remarks

五、注意事项
================================================================================

1. jar 包：所有 XBPQ 站点共用同一个 XBPQ.jar，升级 jar 后所有站点同步生效。
2. 配置值约定：留空 / "空" / "&&" 均视为未配置；布尔型统一用 "0"/"1"。
3. 中英文键混用：中文键优先，CHINESE_KEY_MAP 自动转换，可逐步迁移。
4. 解码问题：搜索关键词 {wd} 自动 URL 编码；详情页标题含 JS %uXXXX 转义会自动解码。
5. 调试：打开调试=1 开启日志（类级只升不降），所有异常通过 SpiderDebug.log 记录。
6. SSRF 防护：拦截内网/127/10/192.168/169.254 等地址；允许用 allow_internal=1 放行。
7. 单条片单解析失败不影响整体列表，各方法均有独立 try-catch 保护。
8. 图片净化：自动过滤 loading.gif / base64 / placeholder 等占位图，回退到原 URL。
9. P2P 链接（magnet/ed2k/thunder/ftp/torrent）直接交给播放器，不走 HTTP，不受 SSRF 拦截影响。
10. isVip() 优先消费 vipFlags 参数（框架传入），未命中时回退内置域名表（vip.ffzy/vip.lz/hd.lz/szionizy）。
11. 选集链接前后缀（epiurl_prefix/epiurl_suffix）在播放线路提取时自动应用到每条集数链接。
12. 视频过滤词（video_filter）命中则强制判定为非视频 URL，优先级高于嗅探词。
