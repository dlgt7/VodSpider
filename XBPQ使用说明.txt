================================================================================
                    XBPQ 影视源 Spider 使用说明
================================================================================

XBPQ 是 CatVodSpider（VodSpider）框架的影视爬虫，以 && 正则截取为核心规则语法，
支持中英文双键配置（XBPQKey 统一登记）、CSS/Jsoup 选择器模式、多线聚合、
Cloudflare/宝塔反爬绕过、图片代理、弹幕加载、M3U8 解析、{{变量}} 模板、
动态域名切换、镜像域名、SSRF 防护等特性。

本文档基于 com.github.catvod.spider.XBPQ.java 与 XBPQKey.java 源码整理，
与代码实现逐一核对，涵盖类结构、方法说明、配置项总览、规则语法与注意事项。

================================================================================
一、类结构与模块划分
================================================================================

本项目为单文件实现 + 键注册表，全部逻辑位于两个类：

1. com.github.catvod.spider.XBPQ（主类，继承 com.github.catvod.crawler.Spider）
   内部静态类/工具：
   ├─ HtmlMatchInfo        HTML 命中信息（标签区间上下文）
   ├─ HtmlNodeHelper       HTML 节点提取辅助
   ├─ JsoupExtractor       Jsoup/CSS 选择器提取（css:/css:// 前缀分流）
   ├─ CssRuleInfo          CSS 规则信息
   ├─ RuleUtils            规则工具（getRegion 区域截取等）
   ├─ NodeExtractionResult 节点提取结果
   ├─ DetailExtractionContext 详情提取上下文
   ├─ SearchFetchResult    搜索抓取结果（content + url）
   └─ SearchNodeResult     搜索节点结果

2. com.github.catvod.spider.XBPQKey（字段命名标准，全项目单一事实源）
   ├─ TABLE 注册表：k(模块, 规范英文键, 规范中文名, 别名...)
   ├─ norm(key)：任意写法 → 规范英文键（未登记原样透传）
   ├─ aliasMap()：非规范写法 → 规范键映射（规则加载时一次性归一化）
   └─ isKnown/cn/module/dump：登记查询与文档输出

3. 关键机制
   ├─ 键归一化：CHINESE_KEY_MAP = XBPQKey.aliasMap()，fetchRule() 时
   │    convertChineseKeys → normalizeRuleKeys 两条链路统一收敛到规范英文键
   ├─ 网络层：OkHttp（com.github.catvod.utils.OkHttp）+ 反爬检测
   │    （isCloudflarePage/bypassCloudflare、isBaoTaWafPage/btwaf cookie 提取）
   ├─ Cookie 合并：Util.mergeCookies（滑块验证后回写规则头）
   └─ 日志：com.github.catvod.crawler.SpiderDebug

二、核心方法说明（@Override）
================================================================================

1. init(Context context, String extend)
   ──────────────────────────────
   初始化入口。extend 支持：
   - http://...json  远程规则文件（fetchRule 懒加载 + 双重检查锁定）
   - clan://...json  本地路径
   - 直接 JSON 字符串  内联配置
   fetchRule() 将 JSON 经键归一化后缓存到 rule 字段，并执行：
   applyDynamicDomain()（动态域名切换）→ 初始化变量表 variableMap。

2. homeContent(boolean filter) → {"class":[...], "filters":{...}}
   ───────────────────────────────
   首页分类构建优先级（buildClassList）：
     0) tryBuildFromJson：cat_mode=0 的分类 JSON 模式（catjsonlist 等）
     1) fenlei 显式配置存在时优先（含 $ 的 "名$值#名$值"）
     2) cateManual 分节对象 / guessCateManualIfNeeded 自动猜测分类
     3) cat_twice 二次截取后 guessRuleCateManual 猜测
     4) class_name + class_value 并行 & 数组
     5) cat_array + cat_title + cat_id 从首页 HTML 提取
     6) tryBuildFromFenlei（fenlei $ 格式）
     7) fallbackClassBuild：fenlei 整串作分类名 + extractCateId(class_url)
   后处理：cate_whitelist 白名单过滤 → insertActionTabs 功能入口插入。
   filter=true 且筛选非空时返回 filters（filter 内联 > filterdata URL 抓取，
   抓取后按 f* 替换组改写；sort_type/sort_value 自动生成 by 排序筛选器）。

3. homeVideoContent() → {"list":[...]}
   ───────────────────────────────
   首页推荐聚合：firstpage 纯数字=每分类条数上限；"名$ID#名$ID"=指定分区；
   hot_recommend=1 无 firstpage 也聚合。跨分类去重（vod_id 优先）。

4. categoryContent(String tid, String pg, boolean filter, HashMap extend)
   ──────────────────────────────────────────────────────────────────────────
   分类列表页。
   - 页码：startpage 起始偏移；offset_paging=1 时 {offset}=(页码-1)*page_size
   - 占位符：{cateId}/{catePg}（{catepg} 小写兼容）
   - 列表模式：网页截取（list_array 等）/ JSON 模式（list_mode + listjson* 字段组）
   - skip_bad_item=1（默认）单条失败跳过；"0"=整页失败
   - 后处理：图片净化（img_attr 懒加载属性/default_pic 兜底）→ 标题清洗
     → filter_word 过滤词剔除 → reverse 倒序 → page_end_marker 终止翻页
   - 页总数：list_total 规则提取 / 共N页 共N条 x/y页猜测，兜底满员 2 空 1
   - 失败重试：mirror_hosts 镜像域名逐个切换；url_append 全局参数追加

5. detailContent(List<String> ids) → {"list":[{vod字段...}]}
   ───────────────────────────────
   - vid 解码：encodeVodId 的 Base64 JSON 自动还原（兼容历史 {"vod_id":vid}）
   - detail_url 模板：先 ${vid} 再 {vid}，兜底 homeUrl 主机拼接
   - 字段提取：CSS 模式（detail_* 规则含 css: 前缀）或 && 截取
   - hexEscapeDecode：链接中 %uXXXX JS 转义解码
   - detail_separator 从纯文本按 label 补缺（导演：/主演：等自动映射 vod_*）
   - detail_merge 将指定 vod_* 字段换行追加到 vod_content（仅增量）
   - 线路：from_array/line_second_cut 提取 → line_name_map 重命名
     → episode_filter 过滤 → episode_sort/episode_dedup 排序去重
     → episode_quality 清晰度优先 → epiurl_prefix/epiurl_suffix 前后缀
     → merge_lines 合并 → empty_play_url 空兜底
   - auto_maccms=1 字段缺失注入 Maccms 默认规则；
     Anal_MacPlayer=2 优先正则解析 MacPlayer 脚本块

6. searchContent(String keyword, boolean quick, String pg)
   ─────────────────────────────────────────────
   - 配置缺失时 guessSearchUrlIfNeeded 自动猜测搜索接口
   - 扁平 search_url：{wd} 自动 URLEncoder.encode，{pg} 经 sea_firstpage 偏移
     （分节 search.url 写法 {wd} 原样替换）
   - search_word_sep 关键词空格替换（如 "+"）
   - searchjson* JSON 字段组优先；search_mode=0 JSON 优先 / =1 网页优先，互为兜底
   - JSON 自动探测：parseJsonSearchResult 递归查找同时含配置 id/name 字段的数组
   - CSS 模式（搜索规则含 css:）→ 传统 && 截取，无结果自动互切
   - quick 参数当前被忽略（快搜与普搜行为一致）

7. playerContent(String flag, String url, List<String> vipFlags)
   ─────────────────────────────────────────────────────────────
   播放解析，按优先级：
     1) isVideoUrl(url) → directResult（parse=0，直链直出）
     2) force_play=1/2 → 直接播放（分类/详情链接直出，可配 play_suffix）
     3) jump_url 非空 → tryJumpPlay（抓取播放页提取真实地址）→ 失败则嗅探
     4) manualVideoCheck=1 → directResult（免嗅直出）
     5) 否则 → buildSniffResult（parse=1，播放器嗅探）
   - play_header JSON 注入 result.header；play_prefix/play_suffix 前后缀
   - play_strip_params=1 播放链接剥离 query
   - danmuUrl 非空注入 danmaku 代理参数
   - isVideoUrl：video_format 嗅探词命中或默认扩展名；video_filter 命中强制非视频

8. proxy(Map<String,String> params)
   ─────────────────────────────────
   proxy:// 总入口分发：
   - do=XBPQ&danmu_url=... → loadDanmu 拉取弹幕，JSON 转 B 站风格 XML
   - M3U8 参数 → doLoadM3u8 拉取内容，相对路径补全，EXTM3U/EXTINF 探测
   - pic 参数 → loadPic 图片回源（secretKey MD5 签名校验）
   - 所有回源强制 SSRF 防护，不受 allow_internal 影响

9. manualVideoCheck() / isVideoFormat(url)
   将 免嗅/嗅探词/视频过滤词 同步给框架嗅探决策，与 playerContent 一致。

10. isFail(int code) / errorCodes / failCodes / successCodes
    响应 JSON code 判定（失败码+错误码 命中即失败；成功码白名单优先）。

四、规则语法详解
================================================================================

────────────────────────────────────────────────────────────────
1. && 正则截取（核心语法）
────────────────────────────────────────────────────────────────

格式："前缀&&后缀" → 截取前缀与后缀之间的内容
（正则转义后 DOTALL 非贪婪匹配；命中多处时全部提取，如列表数组）

示例：
  "title=\"&&\""          → 截取 title="..." 中的值
  "href=\"&&\""           → 截取 href="..." 中的值
  ">&&<"                  → 截取标签内文本
  "类型:&&<br"            → 截取 "类型:" 后到 "<br" 的内容
  "A&&B&&C&&D"            → 四段导航：先取 A..B，再在其中取 C..D

────────────────────────────────────────────────────────────────
2. || 备用选择器
────────────────────────────────────────────────────────────────

"规则1||规则2||规则3" → 依次尝试，取第一个非空结果（applyOrSelector）

────────────────────────────────────────────────────────────────
3. CSS 选择器模式（css:/css:// 前缀）
────────────────────────────────────────────────────────────────

由 isCssModeEnabled 判断：列表/详情/搜索/线路规则含 css: 前缀时启用，
JsoupExtractor 执行提取；CSS 无结果自动回退传统 && 截取。

  "css:.stui-vodlist__box"    → 类选择器
  "css:#id"                   → ID 选择器
  "css:.title->text"          → 取文本
  "css:a->attr(href)"         → 取属性
  "css:.desc->html"           → 取 HTML

────────────────────────────────────────────────────────────────
4. 后处理器标记（applyPostProcessors）
────────────────────────────────────────────────────────────────

值末尾追加标记，提取后执行：
  [替换:旧>>新#旧>>新]  → 文本替换，# 分隔多组；旧串含 * 时转 .* 正则通配
  [包含:关键词]         → 包含关键词才保留，否则返回空
  [不包含:关键词]       → 不含关键词才保留，否则返回空

────────────────────────────────────────────────────────────────
5. {{变量}} 模板替换（resolveVariables）
────────────────────────────────────────────────────────────────

支持最多 10 轮递归展开。内置变量（variableMap）：
  {{主页url}}   → homeUrl 配置值
  {{站名}}      → siteName 配置值
  {{作者}}      → author 配置值
  {{分类url}}   → class_url 配置值
  {{搜索url}}   → search_url 配置值
  {{后缀}}      → domainSuffix 配置值
  {{密钥}}      → secretKey 配置值
  {{域名-c}}    → 动态域名链解析结果（无效时回退 homeUrl）
  {{主页url-c}} → 主页备选解析结果（无效时回退 homeUrl）

示例：
  "搜索url": "{{主页url}}/search.php?wd={wd}&page={pg}"

────────────────────────────────────────────────────────────────
6. 分节规则写法
────────────────────────────────────────────────────────────────

除扁平键外支持子对象写法（加载时自动归一化为扁平键）：
  "cateManual": {"电影":"1","电视剧":"2"}   → 分类映射
  "search": {"url":"...","vod_id":"id","vod_name":"name"}
      → 分节搜索（vod_id 等的值 = JSON 数据字段名）
注意：分节 search.url 的 {wd} 原样替换；扁平 搜索url 的 {wd} 自动 URL 编码。

────────────────────────────────────────────────────────────────
7. 本版不存在的写法（避免误用）
────────────────────────────────────────────────────────────────

  [工具:xxx] 工具链（源码/重定向/解url/解b64/SHA/AES 等）→ 未实现
  [firstPage=...] URL 中括号首页语法 → 未实现（首页聚合用 首页/firstpage 键）
  搜索 URL 末尾 ";post" → postSearch 已定义但未接入调用链，当前无效
  quick 快搜过滤 → quick 参数被忽略，快搜与普搜行为一致

================================================================================
五、特殊功能说明
================================================================================

────────────────────────────────────────────────────────────────
1. 反爬绕过（Cloudflare / 宝塔 WAF）
────────────────────────────────────────────────────────────────
- Cloudflare：isCloudflarePage 检测挑战页（cf-challenge/cf-browser-verification
  等特征）→ bypassCloudflare 提取 cf_clearance cookie 携带重试
- 宝塔 WAF：isBaoTaWafPage 检测（btwaf/检测中/安全检测 等特征）→
  extractBtwafToken 提取 token 生成 cookie 重试
- antiCrawlTimeout 控制反爬重试总预算；Cookie 经 Util.mergeCookies 合并回写

────────────────────────────────────────────────────────────────
2. 图片净化与代理
────────────────────────────────────────────────────────────────
- img_attr 指定懒加载真实地址属性（data-original 等）
- default_pic 默认封面兜底
- PicNeedProxy=1 生成 proxy://pic=URL&key=MD5(pic+secretKey)，
  loadPic 回源校验签名；pic_allow_domains 白名单限定代理域名

────────────────────────────────────────────────────────────────
3. SSRF 防护（isInternalUrl）
────────────────────────────────────────────────────────────────
拦截：
- 危险协议：file/gopher/dict/ftp/jar/netdoc/javascript/mailto
- 内网 IP：127./10./172.16-31./192.168./169.254./0.0.0.0
- localhost / .local / .internal / .localhost
- IPv6：::1 / ULA(fc/fd) / 链路本地(fe80)
proxy() 入口强制拦截，不受 allow_internal 影响。
P2P 链接（magnet/thunder/ed2k/qqdl/btih/urn:btih）直接交给播放器，不走 HTTP。

────────────────────────────────────────────────────────────────
4. 动态域名（域名-c / 主页url-c）
────────────────────────────────────────────────────────────────
applyDynamicDomain()（规则加载时执行）：
  1) 域名-c 展开 {{变量}} + [替换:] 后处理器 → isValidOrigin 校验
  2) 有效则把整份规则中旧 homeUrl 的 origin 全局替换为新 origin（域名切换）
  3) 同时填充 {{域名-c}}/{{主页url-c}} 变量
说明：仅 域名-c 有效时触发切换；主页url-c 只作变量来源。

────────────────────────────────────────────────────────────────
5. 镜像域名与全局参数
────────────────────────────────────────────────────────────────
- mirror_hosts：站点请求失败（5xx/超时）时逐个切换镜像域名重试
- url_append：追加到每次请求 URL 的固定参数（如 "token=xxx"）

────────────────────────────────────────────────────────────────
6. 选集链接前后缀（选集链接加前缀/加后缀）
────────────────────────────────────────────────────────────────
播放线路提取阶段对每条集数链接自动拼接前缀/后缀。
适用于选集链接需要拼接固定路径的场景（如 "/play/" + id + "/1.m3u8"）。

────────────────────────────────────────────────────────────────
7. 编码与解码
────────────────────────────────────────────────────────────────
- encoding：GBK/GB2312 站点响应强制矫正
- hexEscapeDecode：链接中 %uXXXX JS 转义解码（详情链接）
- convertUnicodeToChinese：响应 \uXXXX 转义解码

================================================================================
六、注意事项
================================================================================

1. 配置值约定：留空 / "空" / "&&" 均视为未配置；布尔用 "0"/"1"。
2. 键归一化：XBPQKey.norm 大小写不敏感；未登记键原样透传不报错。
3. 直接播放与详情页互斥：force_play=1/2 时线路/播放解析配置不生效。
4. 多线模式触发：multi_line_array + multi_line_url 同时配置且非空时生效。
5. 线路合并行为：合并后线路名取第一条线路原始名称（非默认"线路"）。
6. 热门推荐：hot_recommend=1 时无 首页 配置也能聚合主页视频。
7. 图片代理密钥泄露则签名失效，请勿公开传播 代理密钥。
8. 单条解析失败不影响整体：各方法均有独立 try-catch，错误仅打日志。
9. bad item 默认跳过：skip_bad_item=1 单条失败剔除该条；"0"=整页失败。
10. vod_id 为 Base64 编码 JSON（encodeVodId），detailContent 自动解码，
    规则书写者无需关心。
11. 视频过滤词优先级高于嗅探词，命中强制判定为非视频。
12. WebView 渲染四键仅注册未实现，运行时输出告警并忽略。
13. 特殊分类链接 / 直播url 仅注册，引擎不消费。
