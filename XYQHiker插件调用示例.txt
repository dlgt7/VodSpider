================================================================================
                         XYQHiker 插件调用示例
================================================================================

目前提供 TVBox / 海阔视界 外挂调用，如果你有能力可以合入你的 jar 包里。

XYQHiker 是 XYQBiu 的演进版，支持中英文双键配置、Jsoup CSS 选择器规则、
首页推荐独立字段、详情页字段细分等增强特性。旧版 XYQBiu 规则可直接复用
（推荐显式将 is_jsoup 系列字段设为 "0" 以保持兼容）。

================================================================================
一、TVBox 外挂调用基本格式
================================================================================

在 TVBox 配置 JSON 的 sites 数组中添加：

{
    "key": "csp_XYQHiker_站点名",
    "name": "站点显示名(XYQHiker)",
    "type": 3,
    "api": "csp_XYQHiker",
    "searchable": 1,
    "quickSearch": 1,
    "filterable": 1,
    "ext": "站点配置JSON的路径或URL",
    "jar": "XYQHiker.jar 的路径或URL"
}

参数说明：
- key：唯一标识，建议 csp_XYQHiker_ 开头
- name：显示名称，建议带 (XYQHiker) 后缀便于识别
- type：固定 3（Spider 类型）
- api：固定 "csp_XYQHiker"
- searchable：1=支持搜索，0=不支持
- quickSearch：1=支持快搜，0=不支持
- filterable：1=支持筛选，0=不支持
- ext：站点规则 JSON，支持以下形式：
    * clan://TVBox/MaoXYQ/xxx.json   （clan 本地路径）
    * http://xxx.com/xxx.json        （网络 URL）
    * ./xxx.json                     （相对路径）
    * 直接 JSON 字符串                （内联配置）
- jar：XYQHiker.jar 的位置，支持 clan:// / http:// / 相对路径

================================================================================
二、ext 配置的三种写法
================================================================================

1. 外部文件引用（推荐）
   "ext": "clan://TVBox/MaoXYQ/影视工场.json"
   "ext": "http://xxx.com/影视工场.json"

2. 内联 JSON（适合简短配置）
   "ext": "{\"title\":\"测试\",\"分类链接\":\"http://xxx.com/{cateId}-{catePg}.html\",\"分类名称\":\"电影\",\"分类名称替换词\":\"1\",\"分类截取模式\":\"1\",\"分类列表数组规则\":\".stui-vodlist__box\",\"分类片单标题\":\".title&&Text\",\"分类片单链接\":\"a&&href\",\"分类片单图片\":\".lazyload&&data-original\",\"链接是否直接播放\":\"0\",\"搜索链接\":\"http://xxx.com/search?wd={wd}\",\"搜索截取模式\":\"0\",\"搜索列表数组规则\":\"list\",\"搜索片单标题\":\"name\",\"搜索片单链接\":\"id\",\"搜索片单图片\":\"pic\"}"

3. 网络云端配置
   "ext": "http://xxx.com/configs/影视工场.json"

================================================================================
六、规则写法迁移指南（XYQBiu → XYQHiker）
================================================================================

1. 数组规则统一
   XYQBiu：cat_arr_pre + cat_arr_suf 二段截取
   XYQHiker：cat_arr_rule 单段或多段 && 导航（推荐）
   迁移示例：
     旧："cat_arr_pre":"ul.vodlist", "cat_arr_suf":"</ul>"
     新："分类列表数组规则":"ul.vodlist&&li"

2. Jsoup 写法切换
   XYQBiu：仅支持 && 正则截取
   XYQHiker：cat_is_jsoup="1" 启用 Jsoup CSS 选择器（推荐）
   迁移示例：
     旧："cat_title":"title=\"&&\""
     新："分类片单标题":".title&&Text" 或 "a&&Text"

3. 详情字段细分
   XYQBiu：只有 proj_actor / proj_plot
   XYQHiker：新增 proj_cover / proj_cate / proj_year / proj_area
   迁移示例：
     新增："封面详情":".vodlist_thumb&&data-original"
     新增："类型详情":".data--span:matches(类型)&&Text"

4. 首页字段独立
   XYQBiu：首页复用 cat_* 字段
   XYQHiker：home_* 独立字段，可与 cat_* 不同
   迁移示例：
     新增："首页片单标题":".title&&Text"
     新增："首页列表数组规则":".stui-vodlist&&li"

5. 中英文键混用
   XYQHiker 支持中英文键混用，中文键优先。
   迁移时无需一次性全部替换，可逐步迁移。

================================================================================
七、注意事项
================================================================================

1. jar 包路径
   - 所有站点共用同一个 XYQHiker.jar
   - jar 可放在本地（clan://）或网络（http://）
   - 升级 jar 后所有站点同步生效

2. 规则 JSON 路径
   - 推荐使用 clan:// 本地路径，加载快且稳定
   - 网络路径需确保服务器可访问且 CORS 配置正确

3. searchable / quickSearch / filterable
   - 直播站通常 searchable=0
   - 无筛选配置的站点 filterable=0
   - quickSearch=1 会调用 searchContent(key, true) 快搜

4. 编码问题
   - 规则 JSON 文件建议保存为 UTF-8 编码
   - 站点编码通过 网页编码格式 / Coding_format 配置（默认 UTF-8）

5. 调试
   - DEBUG="1" 开启 Toast 异常提示
   - 通过 SpiderDebug.log 查看异常堆栈
   - 单条片单解析失败不影响整体列表
   - 验证码 / 频率限制 / btwaf 等异常自动处理

6. 配置值约定
   - 留空 / "空" / "&&" 均视为无效值
   - 布尔型统一用 "0"/"1" 或 "是"/"否"
   - & 分隔列表；包含 & 的值用 ＆＆ 代替
   - || 分隔大分类组（filterdata="EXT" 时）

7. is_jsoup 默认值
   - 新建规则推荐使用 Jsoup 写法（is_jsoup="1"，默认值）
   - 旧版 XYQBiu 规则迁移时显式设为 "0" 保持兼容

8. 数组规则迁移
   - 旧版 cat_arr_pre/cat_arr_suf 仍可使用
   - 推荐迁移到 cat_arr_rule 单段或多段 && 写法
   - 多段写法："容器选择器&&列表选择器"
